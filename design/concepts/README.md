# Tabi design concepts

- `round1/` — 5 avatar restyles (pixel, minimal, kawaii, Gen-Z, clay) and 5 UI directions.
- `round2/` — kawaii state matrix (body × mood, clean + rotten), 3 kawaii variations, UI kit (1–6), 3 chat-card layouts.
- `round3/` — **chosen**: Sticker Tabi 3×3 sheets (clean + rotten) and the minimal status card built from UI-kit pieces 1–6.

Body (columns: full → half → low) follows hotel prices/availability. Mood (rows: happy → meh → sad) follows group-chat activity; rotten when mood < 50.
